# Paradise Nursery 🌿

Paradise Nursery is a React-based online plant shop. Customers can browse houseplants, view their details and prices, add plants to a cart, change quantities, remove products, and see the cart total update.

## Features
- Landing page with the Paradise Nursery name and a **Get Started** button
- Product listing with images, names, descriptions, categories, and prices
- Search and category filtering
- Shopping cart with add, remove, and quantity-update actions
- Cart item count and automatic subtotal calculation
- About Us page
- Responsive layout for desktop and mobile screens

## Technologies
- React
- Redux Toolkit and React Redux
- JavaScript
- CSS

## Run the project locally
1. Install Node.js LTS from https://nodejs.org/
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open the local URL shown in your terminal, usually http://localhost:3000.

## Main assignment files
- `src/App.jsx` — landing page and application navigation
- `src/components/AboutUs.jsx` — company information
- `src/App.css` — styling and landing-page background image
- `src/CartSlice.jsx` — Redux reducers for addItem, removeItem, and updateQuantity
- `src/components/ProductList.jsx` — product listing page
- `src/components/CartItem.jsx` — shopping cart page
